# Storage

Thu muc nay chua du lieu tu dong duoc tao boi `pc_ws_server.py`.

- `temperature.csv`: log nhiet do va khoang cach lay tu ESP32.
- `alerts.json`: danh sach canh bao va su kien tu giao dien.
- `config.json`: cau hinh nguong nhiet do, thong so phat hien chuyen dong va timeout xu ly tu dong.

Cac file nay se duoc tao/ghi de tu dong khi server chay.
